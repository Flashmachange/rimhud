## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Health Overview** | Detailed health, wounds and medical conditions in one panel |
| **Mood Display** | Visual mood bar with breakdown of positive and negative thoughts |
| **Skills Preview** | Quick skill level display without opening the character sheet |
| **Customizable** | Resize, reposition and configure which stats appear in the HUD |
